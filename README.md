# 歴史トラベル

小学生向け・日本史4択クイズ。外部ライブラリ・外部通信・ビルド・サーバー処理は不要です。

## 遊び方と公開

`index.html` をブラウザーで開くと動作します。GitHub Pagesでは、このファイルを含むブランチのルートを公開元に指定してください。サブディレクトリへの配置にも対応しています。

- 1回10問、重複なしのランダム出題
- 回答後すぐ正誤・正解・解説を表示し、ボタンで次へ進む
- 結果表示、再プレイ、タイトルへの移動
- 正解済みの問題をID単位で端末のブラウザーに保存
- 全時代／時代別の選択（10問に満たない時代は選択不可）

1000問版を使用し、「○ / 1000 問クリア」と表示します。同じ問題に何回正解してもクリア数は1問です。タイマー・音声はありません。

## ファイル構成

- `index.html`: ページの土台
- `css/style.css`: レスポンシブ表示と軽い演出（動きを減らす端末設定にも対応）
- `data/questions-1000-quality-v3.js`: 現在使用する1000問（内容は無変更）
- `data/questions-1000-quality-v2.js`: 旧1000問データ（保持・未読込）
- `data/questions.js`: 旧18問データ（保持・未読込）
- `js/core.js`: データ検証・時代定義・ランダム抽出
- `js/storage.js`: 保存処理（バージョン付き形式）
- `js/app.js`: 画面遷移・プレイ状態・回答処理
- `tests/smoke.html`: ブラウザーで開くロジック確認用ページ

## 問題の追加・編集

`data/questions-1000-quality-v3.js` の配列へ以下の形式で追加します。問題はHTMLではなく普通の文字列として表示します。

```js
{
  id: 'edo-004',
  era: '江戸時代',
  question: 'ここに問題文を書きます。',
  choices: ['選択肢A', '選択肢B', '選択肢C', '選択肢D'],
  answer: 0,
  explanation: 'ここに簡単な解説を書きます。'
}
```

`answer` は **0始まり**の位置（0=A、1=B、2=C、3=D）。`id` は全問題で一意にし、公開後は変更・再利用しないでください。問題の意味や正解を大きく変える場合は新しいIDにすると過去のクリアを引き継ぎません。時代名は `js/core.js` の `ERAS` に合わせてください。重複ID、選択肢の数・重複、範囲外の正解などは起動時に検証します。各時代が10問以上になると時代別出題が自動で解放されます。

JavaScriptデータ形式を採用しているため、JSON取得用のサーバーは不要です。約1000問も同じ配列へ追加可能です。将来APIやJSON読み込みに変更する場合も、出題ロジックと保存処理は独立しています。

## 保存について

localStorage の `history-travel.progress.quality-v3.v1` に `{ version: 1, clearedIds: [...] }` を保存します。問題の削除後は、そのIDを表示件数に含めません。保存できない環境では通知し、画面を開いている間はメモリーで継続します。記録はブラウザー・公開先ごとで、別端末には同期されません。ブラウザーデータを消去すると記録も消えます。ファイル直開き時の保存挙動はブラウザーに依存するため、継続利用はGitHub Pagesを推奨します。

## 確認

`tests/smoke.html` をブラウザーで開くと、データ検証・10問抽出・重複防止・時代フィルター・元データ非破壊・未クリア優先を確認できます。画面では回答ボタンの連打防止、10問終了、再プレイ、再読み込み後の記録、スマートフォン幅を確認してください。


## 1000問版の出題・保存

未クリア問題の抽出重みは2、クリア済みは1です。復習も含めてランダムに10問選びます。同一プレイではIDだけでなく同一問題文も重複を避けます。進捗は1000個のID単位で集計します。

v3の保存先は `history-travel.progress.quality-v3.v1` です。v2の `history-travel.progress.quality-v2.v1` と旧18問版の `history-travel.progress.v1` は保持し、自動移行しません。同じIDでも問題内容が異なる可能性があるため、v3の進捗は独立して開始します。破損した保存形式は空として開始し、不正なID型は除外します。現在のデータにないIDはクリア件数に含めません。

`tests/smoke.html` は実1000問・全時代・未クリア優先を検証します。`tests/integration.html` はローカルHTTPサーバー経由で開き、全時代と全10時代の完走・保存復元・破損保存・保存不可を検証します。後者はiframe内の保存をテスト用メモリーに置き換え、実際のクリア記録に影響しません。
